# VOZI I POLOŽI

Browser igra za https://autoskolebeograd.com/ u kojoj igrač vozi kroz situacije sa vozačkog ispita u Beogradu.

Kompletan opis igre je u [docs/brief.md](docs/brief.md).

## Pokretanje

Igra je jedan fajl, `index.html`. Otvori ga u pregledaču (Chrome, Firefox, Safari). Potrebna je internet veza zbog Three.js biblioteke i fontova.

- `↓` kočnica
